# 关于

你好，欢迎来到我的博客！👋

这里会记录一些生活点滴与技术笔记。

> 这是一份示例「关于」页面。登录后台 `/admin` → **关于页**，即可在线修改这里的内容；也可以直接编辑仓库中的 `data/about.md`。

## 本站

本站基于 [NavBlog](https://github.com/dragonadd/nav1) 搭建：

- 纯静态部署，文章以 Markdown 形式保存在 Git 仓库中；
- 可以在线进入 `/admin` 后台写作，保存后自动提交到仓库并触发重新部署；
- 主题样式参考 [Fuwari](https://github.com/saicaca/fuwari)。
