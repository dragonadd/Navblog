# 本地 Fuwari 适配记录

对比基准是 `D:/deepseek-work/fuwari` 中的 NotionNext / Next.js 适配版；没有引入其框架代码，也不将本次改造称为官方 Astro 最新版本同步。

## 已完成

- 首页及首页分页专属 Hero，文章等内页不显示站点横幅。
- 列表封面失败降级，默认封面、200–360px 列宽、放大、摘要与标签开关。
- 调色盘小屏宽度、当前 HEX 与复制、色相 0、固定色相启动及步长修正。
- 最新文章、联系正反面卡片、侧栏模块及导航开关；联系卡片默认关闭，填写内容和链接后开启。
- `hideSidebar: true` 文章 front matter 与后台编辑入口，保存后全宽阅读。
- 首页、分类、标签、搜索支持可选自动加载，默认继续分页；保留按钮和无观察器时的手动加载。
- 年月归档锚点与列表日期跳转，静态 HTML 同步年月锚点。
- Angular 模板渲染搜索关键词标记，文本继续由 Angular 转义。
- 文章封面位置、元信息、分享、版权、上下篇、评论开关；分享优先浏览器原生分享，始终提供复制链接。
- 工具微动效、减少动态效果偏好，以及手机目录关闭和导航。

## 配置与兼容

后台“站点设置 → Fuwari 布局与阅读体验”集中管理新增设置。旧 JSON 缺少字段时由 `src/shared/theme-settings.ts` 补齐默认值，明确的 `false` 保留。设置通过既有 Git API 保存，正式站点重新构建后生效。本地演示仅修改浏览器副本。

翻转卡片使用 Angular 状态与 CSS 3D 变换。触屏和键盘可通过按钮切换；悬停效果仅用于支持悬停的设备。无效联系链接不提供跳转。

本次按批准的三个实施批次完成；此前建议暂缓的第三方广告、外部插件插槽、Lenis 和自定义光标未加入。参考目录只有这些外部依赖的引用，缺少实际组件实现。
