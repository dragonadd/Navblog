# 验收缺陷修复记录

范围是 2026-11-11 已获确认的验收报告 1–11，以及权限测试和 Toast 无障碍反馈两项改进。保留现有 Angular/TypeScript、静态部署和 Git API 架构，无新增依赖。

| 原问题 | 修复方式 | 验证 |
| --- | --- | --- |
| Cloudflare 回退覆盖静态资源 | 仅为具体后台子路由回退，文章、JS/CSS、auth 和 RSS 不匹配 | 根路径及 `/blog/` 的真实构建规则检查 |
| 文章/设置/关于页旧窗口覆盖 | 读取内容快照，保存前核验最新文件；正文和索引携带条件版本 | 两个独立 AdminStore 的旧窗口、改名和损坏索引回归 |
| 子目录绕过加密/草稿校验 | 仅将经过顶层校验的非草稿文件复制到 generated/published-posts，资产 glob 限定 `*.md` | 嵌套明文夹具不得出现在公开目录 |
| 迟到 401 清除新会话 | fetchUser 的成功及失败都核对原 Token 和登录版本 | 新会话不被旧响应注销 |
| 草稿摘要进入前端包 | 仓库索引保留完整列表，公开索引过滤草稿，开发和生产资源均不含草稿 | 逐文件扫描草稿正文与摘要标记 |
| 手机菜单忽略开关 | 与桌面统一用 visibleMenus | 手机及桌面实际开关验收 |
| 动态日期跳首页 | Angular RouterLink `/moments` 加 fragment | 点击日期后仍停留时间线 |
| admin 名称误判布局 | 初始地址去掉部署前缀，只判断站内首段 admin | 文章/分类/标签及部署前缀回归 |
| 404 残留正文目录 | 无文章时也清空正文、目录、密码状态并增加请求版本 | 组件复用、迟到响应和浏览器后退回归 |
| 非法 URL 停止预览/读取兄弟目录 | 返回 400；解析路径与真实文件均限制在公开根目录；处理读流错误 | 独立临时预览服务器的 URI、越界和后续请求 |
| 元信息美元符号误替换 | 动态 HTML 替换值统一用回调，按字面插入 | 标题/摘要 `$&`、`$$`、`$'` 真实构建 |
| 权限测试覆盖不足 | 表驱动覆盖三平台 push、GitLab 项目/组角色与归档拒绝 | test-admin-auth.ts |
| Toast 无播报 | 错误 role=alert，普通反馈 role=status，aria-atomic | 浏览器操作反馈与辅助属性检查 |

独立复核补修了一个导入兼容回归：文章索引允许顶层文件名中的点号和空格，继续拒绝空值、目录分隔符、父目录语义与控制字符。回归测试同时覆盖合法导入和越界拒绝。本地演示的通用版本冲突提示改称“文件”，公告设置提示同步为实际的侧栏位置。

本轮不使用真实 Token 写仓库，不推送或部署。Gitee 没有本项目使用的多文件原子提交方式，预检及逐文件 SHA 可以阻止旧版本覆盖，途中失败仍可能部分提交，需检查仓库后重新读取。

原有范围限制保留：PWA 无离线缓存，安装 PNG 只用本地文件；碎碎念无图片/点赞/评论；旧动态编辑暂不推进 sitemap 日期。公开 Git 历史和已下载的认证密文需要靠 Token 撤销/轮换处理，不能由删除文件撤销。
