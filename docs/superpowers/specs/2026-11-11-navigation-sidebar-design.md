# 侧栏模块与两级导航

用户要求更新 README 的自定义登录密码说明，允许每个桌面侧栏模块选择左/右，并完善顶部菜单显隐与二级菜单。沿用已经授权的持续执行方式，在当前项目完成，不推送或部署，不修改原文章和演示数据。

- README 区分加密 Token 与密码、公开站点资源与私有仓库，说明弱密码的离线猜解风险，并准确列出个人/组织私有仓库的托管计划条件。
- 个人资料、公告、统计、最新文章、联系卡片、分类、标签、目录分别设置左/右。旧 sidebarReverse 作为未设置模块位置时的默认值；显式模块设置优先。单侧保持两栏；左右都有可见模块时扩大桌面容器并显示三栏。手机按原顺序显示一份侧栏。文章 hideSidebar 继续隐藏全部侧栏，关闭唯一公告后不保留空栏。
- 六个内置导航与搜索/手机菜单入口沿用布尔开关。额外父菜单和子菜单分别支持显示/隐藏、新窗口；二级菜单可只用名称分组，也可保留父链接。支持两层，桌面点击展开，手机嵌套展开，Escape/点击外部/调整视口时关闭。桌面长导航在中间区域滚动，弹出子菜单位于该区域外，保持导航栏 60px 吸顶。
- 设置保存在原 data/settings.json，通过现有 AdminStore/Git API 保存。保留隐藏菜单数据、旧设置兼容和无障碍键盘操作。不增加依赖。

实现选择：使用现有 Angular signal、FormsModule 和 Fuwari 卡片。桌面与手机使用 matchMedia 切换实际组件结构，避免重复组件与重复 ID；默认模块顺序不变。现有公告状态服务用于判断侧栏实际可见模块。

验收：兼容/配置校验/设置保存回归，Angular 构建和静态预渲染，1440×1000 与 390×844 深浅色、左右混排、全宽文章、菜单显隐/展开/键盘关闭、长菜单边缘位置，原 data 文件哈希不变。
