# 碎碎念 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans; continue the authorized work in the current project.

**Goal:** 提供纯静态短文本时间线与 Git API 后台发布、编辑、删除。
**Architecture:** 借鉴 Handsome cross.php/say.php 的头像、时间线、日期和短文本展示，用 Angular 重写。复用 BlogService、AdminStore、GitService 与 prepare/postbuild；data/moments.json 为唯一数据文件。
**Tech Stack:** Angular 21、TypeScript、Tailwind、Node；无新依赖。
**Spec:** 用户已批准的第三任务及本轮“那就开始”：短文本、时间、换行；无图片/点赞/评论/RSS聚合扩展。

## Constraints

- 数据 {id,date,text,updated?}，UUID、ISO 时区时间、纯文本最多 5000 字符，按发布时间倒序。
- /moments 前台和 /admin/moments 后台；内置导航“碎碎念”。
- JSON 损坏/重复 ID/非法日期阻止写入，不能用空数组覆盖原数据。
- 存储通过现有 Git API；本地演示只写浏览器副本。删除采用页内确认，保留取消。
- 构建输出 moments 静态 HTML 与 sitemap，模板转义文本并保留换行。
- 初始 data/moments.json=[]，不编造用户动态。
- 用户现有工作区和未提交修改保留，本任务不推送/部署。

## Tasks

1. 共享模型与验证：src/shared/moments.ts、types.ts；scripts/test-moments.ts 写失败测试并验证 RED，再实现并 GREEN。
2. 保存与公开读取：AdminStore CRUD 读取最新 JSON；BlogService/GitService 支持演示数据；prepare 生成 JSON；postbuild 静态/sitemap。测试保存/失败不写/演示不访问网络。
3. 前台时间线、后台编辑管理、导航；生产构建与手机/桌面 CRUD 验收；独立审查；清理临时数据并恢复用户原设置。

## Review Focus

- 恶意 HTML 只显示文本，不解析；超长/空文本与非法时间拒绝。
- 读取失败不覆盖数据，保存失败不更新列表，编辑/删除不丢失其他条目。
- 时间采用偏移明确的 ISO 值，datetime-local 编辑转换不漂移。
- 首页与后台手机导航能找到碎碎念，分页/全宽现有文章正常。
- 导出演示数据包含新文件，正式构建无需新增服务器。
